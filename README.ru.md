# BB Windows

Windows-клиент для [BB](https://github.com/get-bb/bb): подключение к своему
серверу, работа с агентами и встроенный браузер, которым агент может управлять
через локальный WSL-демон.

[Скачать 0.2.0](https://github.com/elstatic/bb-windows/releases/tag/v0.2.0) ·
[English](README.md) · [Подробная документация](apps/windows-client/README.md)

Версия для тестирования. Установщик пока без цифровой подписи, обновления — вручную.

## Возможности

- Установщик для Windows x64, ярлыки на рабочем столе и в меню «Пуск».
- Прямое подключение к BB по HTTP(S), в том числе через Tailscale Serve.
- Подключение через профиль Windows OpenSSH и восстановление после обрыва.
- Встроенные вкладки браузера с сохранением сессий.
- Управление браузером агентом: открытие страниц, клики, ввод текста и скриншоты.
- Ограниченный по вкладкам и времени доступ; кнопка «Забрать управление» отзывает его.
- Меню, горячие клавиши, поиск, контекстные меню и несколько окон.

Приложение использует интерфейс и desktop-компоненты исходного BB.
Сервер и агенты продолжают работать на существующей инфраструктуре.
Сервер и демон в установщик не включены.

## Установка

1. Скачай [BB-Windows-0.2.0-x64-Setup.exe](https://github.com/elstatic/bb-windows/releases/download/v0.2.0/BB-Windows-0.2.0-x64-Setup.exe).
2. Установи и запусти **BB Windows**. Windows может показать предупреждение из-за отсутствия подписи.
3. Выбери «Адрес сервера» и введи адрес своего BB. Если Windows видит сервер через Tailscale Serve, достаточно его HTTPS-адреса.
4. Для сервера, доступного только через SSH, выбери «SSH-туннель» и укажи свой настроенный профиль Windows OpenSSH.

Настройки подключения доступны через **BB → Подключение…**.
Установка новой версии поверх старой сохраняет настройки и браузерные сессии.
Контрольные суммы SHA256 находятся на странице релиза.

## Управление браузером

Нужен локальный WSL-демон BB, уже подключённый к тому же серверу, и Node.js 22.19+
в его дистрибутиве. По умолчанию используется основной дистрибутив WSL;
другой можно выбрать в настройках подключения. Для SSH или альтернативного
адреса укажи также исходный адрес сервера, использованный при подключении демона.

Новые вкладки агента используют отдельные профили. Для управления личной
вкладкой нужно явно передать доступ. Его можно отозвать в любой момент.
Без локального WSL-демона интерфейс сервера и ручной браузер остаются доступны.

## Ограничения

- Импорт авторизации из Windows Chrome/Edge пока отсутствует: входить на сайты нужно внутри приложения.
- Подключение через аккаунт BB Connect пока отсутствует: доступны адрес сервера и SSH.
- Нет автообновлений и цифровой подписи установщика.
- Локальные агенты и провайдеры работают через WSL.
